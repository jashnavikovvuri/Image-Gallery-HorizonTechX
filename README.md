# Image Gallery

A responsive Image Gallery project built using HTML, CSS, and JavaScript.

## Features

- Image Gallery Layout
- Next and Previous Navigation Buttons
- Hover Effects
- Smooth Transitions
- Responsive Design for Mobile and Desktop
- User-Friendly Interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

Image-Gallery-HorizonTechX/
│
├── index.html
├── style.css
├── script.js
├── image1.jpg
├── image2.jpg
├── image3.jpg
├── image4.jpg
└── image5.jpg

## How to Run

1. Download the project files.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Use Next and Previous buttons to navigate through images.
